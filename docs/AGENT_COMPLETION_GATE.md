# Agent Completion Gate

An agent is not complete because it has a name or a description. Every registered role must have stable identity, mission, concrete duties, required knowledge before routing, explicit boundaries, declared capabilities, collaborators, lifecycle participation, a communication contract, a no-roleplay boundary, and activation-readiness validation.

The organization must have one shared purpose, Spark-mediated internal coordination, Bud as the only user-facing conversational boundary, Orbit retained as browsing/discovery intelligence, Navigator retained as operational/action intelligence, honest unavailable states when a real capability/provider does not exist, a Bud/Spark presentation boundary that simplifies complex work, authorized personalization without inferring sensitive traits, and no fabricated agent conversations, actions, memories, provider connections or results.

Historical repository material is evidence for reconciliation, not permission to copy obsolete runtime behavior.

This gate does not claim that external providers are connected. It establishes that the organization has a real internal contract ready for legitimate capabilities when they exist.

No later product layer should be declared active until this gate passes.


## Runtime completion requirements

The organization is not complete merely because every role has metadata. Every registered role must execute through the shared runtime contract and return a truthful structured outcome. Runtime outcomes distinguish completed work, missing user input, routing needs, verification needs, authorization blocks, unavailable capabilities, network timeouts and genuine failures.

A timeout caused by a fluctuating or unavailable connection is reported as a timeout. It is not represented as “the agent does not know.” When information or permission is missing, the responsible path identifies what is needed next and routes the request appropriately.

Bud remains the only student-facing identity. Bud does not call itself AI in normal conversation and does not expose Spark, Oracle, specialists, service names, routing, internal evidence or internal handoffs. Internal collaboration is implementation data, not student-facing dialogue.

Educational context is classified by purpose. Legitimate academic anatomy, medical education and art education are not automatically treated as sexual content merely because accurate human anatomy or nudity is present. Explicit sexual purpose is classified separately, and unclear context is escalated rather than guessed.

Oracle is a registered core intelligence role. It remains internal like every role except Bud.
